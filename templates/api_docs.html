REST API Reference

Send Teams notifications programmatically using curl or any HTTP client. No browser session required — authenticate with an API key.

No login required X-API-Key header JSON request & response

🔑 API Key Setup

Set the API_KEY environment variable on the server before using these endpoints:

  • Linux / macOS: export API_KEY="your-secret-key"
  • Windows (PowerShell): $env:API_KEY = "your-secret-key"
  • Docker / .env file: API_KEY=your-secret-key

Then pass the key in every request header: X-API-Key: your-secret-key

Endpoints

GET
/api/v1/user/{username}
Look up a Microsoft Entra ID (Azure AD) user by email, UPN, or display-name alias.
▾
🔐 Requires X-API-Key header. Returns HTTP 401 if the key is missing or invalid.

Path Parameters

NameTypeDescription
usernamerequired string The user's email address, UPN, or display-name alias to search for in Entra ID.

cURL Example

curl -X GET "{{ base_url }}/api/v1/user/truongtd3" \
     -H "X-API-Key: your-secret-key"

Response

{
  "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "displayName": "Truong Duc",
  "mail": "truongtd3@company.com",
  "userPrincipalName": "truongtd3@company.com"
}
// 401 — Missing or invalid API key
{ "error": "Invalid API key." }

// 404 — User not found
{ "error": "User 'truongtd3' not found in Microsoft Directory." }

            POST
            

                
/api/v1/send

                
Send a private Teams Activity notification to a specific user.

            

            ▾
        

        


            

                🔐
                Requires X-API-Key header. Returns HTTP 401 if the key is missing or invalid.
            


            
Request Body (application/json)

            

                
FieldTypeDescription

                

                    target_userrequired
                    string
                    Recipient's email, UPN, or display-name alias in Entra ID.
                

                

                    messagerequired
                    string
                    Plain-text message body to deliver as a Teams Activity notification.
                

            


            

                
cURL Example

                
curl -X POST "{{ base_url }}/api/v1/send" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: your-secret-key" \
     -d '{
       "target_user": "truongtd3@company.com",
       "message": "Hello from the API!"
     }'

                
            


            

                
Response

                

                    
                    
                

                


{
  "success": true,
  "recipient": {
    "username": "truongtd3@company.com",
    "displayName": "Truong Duc",
    "userPrincipalName": "truongtd3@company.com",
    "id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  },
  "message": "Hello from the API!",
  "status": "Notification sent successfully via Teams Activity API"
}

                

                


// 400 — Missing fields
{ "error": "Missing required field: 'message'" }

// 401 — Bad API key
{ "error": "Invalid API key." }

// 404 — User not found in Entra ID
{ "success": false, "error": "User '...' was not found in Microsoft Entra ID." }
